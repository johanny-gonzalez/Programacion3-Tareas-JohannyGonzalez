# Práctica de Programación 3 - Tarea 3

Hola, este es mi repositorio para la Tarea 3 de la materia Programación III. Aquí subí la solución modular hecha en Java, dividida en varias clases para que el código quede ordenado y sea fácil de probar desde un menú interactivo.

## 📁 Estructura del Proyecto

Todos los archivos con el código fuente están dentro de la carpeta `Src/`:

* `Main.java`: Es la clase principal. Muestra el menú en la consola para elegir qué ejercicio ejecutar.
* `Inventario.java`: Ejercicio 1. Se encarga de la gestión de productos, calcula precios totales, muestra alertas de stock bajo y ordena los artículos de mayor a menor precio.
* `Calificaciones.java`: Ejercicio 2. Procesa las notas de los estudiantes, saca los promedios, determina quiénes aprobaron o reprobaron y busca las calificaciones más altas y bajas.
* `BusquedaProducto.java`: Ejercicio 3. Realiza búsquedas de productos en arreglos usando coincidencias parciales de texto.
* `ProcesadorCSV.java`: Ejercicio 4. Trabaja con cadenas de datos tipo CSV (separadas por comas), calcula salarios promedio y filtra por departamento y correo.
* `ValidadorEstudiante.java`: Ejercicio 5. Contiene las validaciones de entrada para nombres completos, matrículas y correos institucionales.
* `CalculadoraFechas.java`: Ejercicio 6. Maneja fechas usando `Calendar` y `SimpleDateFormat`, calcula la edad y los días que faltan para fin de año.

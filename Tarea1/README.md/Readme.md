## Descripción
Este proyecto integra diez ejercicios prácticos desarrollados en Java, abarcando desde conceptos básicos como estructuras de control y tipos de datos, hasta conceptos fundamentales de la Programación Orientada a Objetos (POO) como encapsulamiento, herencia y polimorfismo.

Todos los ejercicios se ejecutan a través de un menú interactivo en consola.

## Tecnologías utilizadas
- Java
- JDK 17
- Visual Studio Code
